Privacy policy

daily-feed · last updated October 6, 2026

Who this applies to

daily-feed is a personal tool used only by its owner, on the owner's own Google accounts. It is not offered to the public.

What data is accessed

With the owner's consent, daily-feed requests read-only access to Gmail (https://www.googleapis.com/auth/gmail.readonly). It reads message metadata (sender, subject, date, labels) and short snippets of recent messages.

How it is used

The data is used only to produce the owner's private summary of messages that may need attention. It is not used for advertising, profiling, or training machine-learning models, and it is not sold or shared with third parties.

Storage

OAuth tokens and a list of already-processed message IDs are stored only on the owner's own computer. Full email content is not stored. Short summaries appear only in the owner's private feed.

Google API Services User Data Policy

daily-feed's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
