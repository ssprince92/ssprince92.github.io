daily-feed

A personal, single-user tool. It is not a public service.

daily-feed builds a private daily summary for its owner: local food deals, plus a read-only look at the owner's own Gmail inboxes, to point out messages that need a reply, upcoming bills, deadlines and package updates.

It uses the Gmail API with the read-only scope (gmail.readonly). It never sends, deletes or changes email.
